# Canvas Workspace - Quick Start Guide

## 🚀 Quick Start (5 minutes)

### Step 1: Access Canvas Workspace

1. Log in to your account
2. Click **"Canvas"** in the sidebar
3. You'll see the Canvas Workspace dashboard

### Step 2: Create Your First Canvas

**Option A: Use a Template**
1. Click **"New Canvas"** button
2. Choose a template:
   - **Brainstorming** - For idea generation
   - **Project Planning** - For task management
   - **Flowchart** - For process mapping
   - **Documentation** - For technical docs
   - **Cornell Notes** - For learning
3. Enter a name (e.g., "My First Canvas")
4. Click **"Create Canvas"**

**Option B: Start Blank**
1. Click **"New Canvas"**
2. Select **"Blank Canvas"**
3. Enter a name
4. Click **"Create Canvas"**

### Step 3: Add Content

You'll see a toolbar at the top with different tools:

**Quick Actions:**

1. **Add a Heading**
   - Click the 📑 heading icon
   - Type your heading
   - Change level (H1-H6) in the dropdown

2. **Add a Sticky Note**
   - Click the 📌 sticky note icon
   - Type your note
   - Click the color palette to change color

3. **Add a Task List**
   - Click the ☑️ task list icon
   - Click **"Add Task"** to add items
   - Check off completed tasks

4. **Add a Shape**
   - Click any shape icon (⬜ ⭕ 🔺)
   - Double-click to add text
   - Click palette to change color

5. **Add Code**
   - Click the 💻 code icon
   - Select language from dropdown
   - Paste or type your code

### Step 4: Organize

**Connect Nodes:**
1. Select a node (click on it)
2. Drag from the small circle at bottom
3. Drop on another node's top circle
4. A line appears connecting them

**Move Nodes:**
- Simply drag nodes to reposition

**Delete:**
- Select a node
- Press **Delete** key

### Step 5: Save & Export

**Save:**
- Click **"Save"** button (top right)
- Canvas is saved to database

**Export:**
1. Click **"Export"** dropdown
2. Choose format:
   - **PNG** - For sharing as image
   - **JSON** - For backup/transfer

## 💡 Pro Tips

### Tip 1: Use AI Suggestions
- After adding a few nodes, the **AI Assistant** will appear
- Shows suggestions for:
  - What to add next
  - How to organize better
  - Connections to make

### Tip 2: Template Workflow
1. Start with a template closest to your needs
2. Modify the pre-filled content
3. Add your own nodes
4. Delete what you don't need

### Tip 3: Color Coding
- Use different colors for sticky notes:
  - 🟡 Yellow - Ideas
  - 🩷 Pink - Questions
  - 🔵 Blue - Facts
  - 🟢 Green - Actions
  - 🟣 Purple - Important

### Tip 4: Canvas Organization
- Put main ideas at the top
- Use headings to separate sections
- Connect related concepts
- Keep important items in the center

### Tip 5: Keyboard & Mouse
- **Click** - Select node
- **Double-click** - Edit mode
- **Drag** - Move node
- **Delete key** - Remove selected
- **Ctrl/Cmd + S** - Save (in browser)

## 📋 Common Workflows

### Workflow 1: Meeting Notes
1. Add heading with meeting title
2. Add sticky notes for each topic discussed
3. Add task list for action items
4. Connect notes to relevant tasks

### Workflow 2: Project Kickoff
1. Use **Project Planning** template
2. Rename phase titles
3. Add tasks for each phase
4. Add deadline sticky notes
5. Export as PNG to share with team

### Workflow 3: Learning New Concept
1. Use **Cornell Notes** template
2. Add heading with subject
3. Put key points in sticky notes (left)
4. Add detailed notes in text blocks (right)
5. Summarize at bottom

### Workflow 4: API Documentation
1. Use **Documentation** template
2. Add headings for each endpoint
3. Add code blocks with examples
4. Add text blocks for descriptions
5. Add images for diagrams

## ❓ FAQ

**Q: How many nodes can I add?**
A: No hard limit, but keep it under 50 for optimal performance.

**Q: Can I collaborate with others?**
A: Not yet - coming in a future update!

**Q: Can I embed videos?**
A: Not directly, but you can add image thumbnails with links.

**Q: Can I change canvas background?**
A: Currently uses a dot grid pattern. Custom backgrounds coming soon.

**Q: Are my canvases private?**
A: Yes, only you can see your canvases unless you export and share.

**Q: Can I undo changes?**
A: Press Ctrl/Cmd + Z for undo. Or export JSON before major changes.

**Q: How do I search my canvases?**
A: Use browser search (Ctrl/Cmd + F) on the Canvas list page.

**Q: Can I change node size?**
A: Some nodes (shapes) have fixed sizes. Others grow based on content.
